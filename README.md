# Единица и ноль

Короткий научно-популярный фильм об энтропии, стреле времени и о том, может ли Вселенная развиваться по спирали.

**Смотреть:** https://amchercashin.github.io/entropy-film/

Шестнадцать глав: сливки в кофе, подсчёт микросостояний на сетке 10 × 10, шахматная ловушка, возражение Лошмидта и гипотеза прошлого, гравитационная энтропия, горб сложности, теорема Лиувилля, спиновое эхо, парадокс Гиббса, конформная циклическая космология Пенроуза, растущий потолок энтропии (Лейзер, Фраучи), лестница уровней и точка Януса.

Фильм — это файл `index.html`. Графика и анимация рисуются на canvas, музыка и звуковые эффекты синтезируются через Web Audio. Озвучка записана заранее нейроголосом «Светлана» (Microsoft) и лежит в `audio/`, поэтому во всех браузерах звучит одинаково. Если файл не загрузится, реплику прочитает голос браузера.

Текст озвучки берётся из самого `index.html`. После правки реплик запишите её заново:

```
pip install edge-tts
python tools/make_voice.py
```

Управление: пробел — пауза, ← → — главы, F — полный экран, V — голос, M — музыка, E — эффекты, C — субтитры.
